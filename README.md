This project presents a comprehensive SQL-based analysis of Indian equity market data for six major NSE-listed large-cap stocks across the Auto and IT sectors: Bajaj Auto, Eicher Motors, Hero MotoCorp, TVS Motor, Infosys, and TCS. Using daily trading data from 2021–2025, the study evaluates stock price performance, volatility, liquidity, turnover, delivery behavior, and sector-level trends to understand comparative risk-return dynamics and market behavior.
The raw datasets were imported into MySQL Workbench and extensively cleaned using SQL techniques to resolve formatting inconsistencies such as Excel serial dates, text-encoded numeric values, Indian comma separators, missing values, and invalid entries. A structured data-cleaning pipeline was implemented to standardize dates, normalize null values, and convert financial columns into optimized numeric data types for accurate analysis.
The analytical phase includes price performance summaries, volatility analysis, liquidity and turnover comparisons, delivery percentage analysis, monthly trends, top trading sessions, annual return analysis, and 52-week high-low studies. The findings reveal a clear divergence between sectors: Auto stocks delivered stronger growth and momentum with higher volatility, while IT stocks demonstrated greater stability, liquidity, and institutional participation. Overall, the project highlights how SQL can be effectively used for financial data cleaning, transformation, and advanced market analysis while providing practical insights into portfolio balancing between high-growth cyclical stocks and defensive large-cap IT companies.
